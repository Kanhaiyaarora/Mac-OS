# 🍎 macOS Portfolio

A modern **macOS-inspired developer portfolio** built with **React**, **SCSS**, and **Vite**. The portfolio recreates the macOS desktop experience, allowing visitors to interact with applications through a functional Dock, draggable windows, and smooth UI animations.

## 🚀 Live Demo

**🌐 https://mac-os-cvui.vercel.app/**

---

# ✨ Features

* 🍎 macOS-inspired desktop interface
* 🖱️ Interactive Dock
* 🪟 Draggable application windows
* ⚡ Smooth animations
* 🎨 Clean and responsive UI
* 📱 Mobile-friendly layout
* 🔗 External links integrated with desktop apps

---

# 🖥️ Dock Applications

| Icon        | Description                          |
| ----------- | ------------------------------------ |
| 🐙 GitHub   | Opens the GitHub application         |
| 📝 Notes    | About Me / Notes window              |
| 📄 Resume   | Resume viewer                        |
| 📬 Contact  | Contact information and social links |
| 📅 Calendar | Opens Google Calendar                |
| 🎵 Spotify  | Spotify widget                       |
| 📧 Mail     | Opens default mail client            |
| 💼 LinkedIn | Opens LinkedIn profile               |
| 💻 CLI      | Interactive terminal window          |

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/mac-os-portfolio.git
```

Move into the project

```bash
cd mac-os-portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
